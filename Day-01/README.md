\## 🧠 Key Concepts



\### 🔹 Types of Languages

\- Procedural → step-by-step execution (C)

\- Functional → based on functions (Haskell)

\- OOP → objects and classes (Java, Python)



\### 🔹 Static vs Dynamic

\- Static → type fixed (Java)

\- Dynamic → type decided at runtime (Python)



\### 🔹 Memory

\- Stack → stores primitives, function calls

\- Heap → stores objects
