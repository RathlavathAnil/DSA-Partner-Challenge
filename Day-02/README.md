\## 🧠 Key Concepts



\### 🔹 Variables



Variables are used to store values in memory.

Example:



```java

int age = 21;

```



\### 🔹 Data Types



\* int → whole numbers

\* double → decimals

\* char → single character

\* boolean → true/false

\* String → text



\### 🔹 Input \& Output



\* Input → Scanner

\* Output → System.out.println()



\### 🔹 Debugging



\* Syntax Error → compile time

\* Runtime Error → during execution

\* Logic Error → wrong output
